# Shaik Nageena — Portfolio

A responsive personal portfolio showcasing AI/ML and full-stack projects, education, internship experience, certifications, and contact information.

## Built with

- HTML
- CSS
- Vanilla JavaScript

## Run locally

From the project directory, start a static HTTP server:

```powershell
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Project structure

```text
.
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── images/
    └── resume.pdf
```

Keep the `assets` directory alongside the HTML, CSS, and JavaScript files so local images and the resume link continue to work.

## Deploy

This is a static site and requires no build command. To deploy with Vercel, import this GitHub repository and use the **Other** framework preset with the repository root as the output directory.
